# Sytra Studio 1.3.0

This is the first packaged release of the 1.3 update. It restores the published `mri` version in the frontend lockfile so GitHub Actions can install dependencies from scratch.

- Chat and Datasets follow the selected interface language and appearance preferences.
- Dataset Fabric uses native token counting and keeps training and validation datasets separate. The local agent schedule tests cover recurrence and timer cleanup.
- The Sytra-Helix benchmark records step times and peak VRAM for two Mixtral checkpoints. See the [training benchmark](../HELIX_TRAINING_BENCHMARK.md).
- Web Search uses the Wikimedia Action API for Wikipedia and supports Brave Search for general web queries. The [Sytra Cloud Agent guide](../../cloud-agent/README.md) covers the separate Vercel deployment, allowed origins, AI Gateway billing, and optional schedules.

See the [1.3 migration guide](1.3.0.md) for the full feature list and upgrade instructions.
